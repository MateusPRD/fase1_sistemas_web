# PetShop Amigo Fiel — Arquivo de Ajuda

Este repositório contém o site (Fase 1) do projeto da disciplina **Fundamentos de Sistemas Web**, desenvolvido para um petshop fictício.

## Sobre o projeto

O site é uma plataforma online de comércio de produtos e serviços para pets, construída apenas com **HTML puro**, sem uso de CSS/Bootstrap ou JavaScript (conforme exigido na Fase 1 do projeto).

## Estrutura dos arquivos

| Arquivo | Descrição |
|---|---|
| `index.html` | Página inicial do site: apresentação do petshop e menu de navegação. |
| `produtos.html` | Página de produtos, dividida em 3 categorias: Acessórios, Rações não perecíveis e Produtos de higiene e limpeza. Cada categoria apresenta 2 produtos, com foto, descrição e valor. |
| `servicos.html` | Página de serviços do petshop: banho e tosa, com e sem tele-busca, com descrição e valor de cada opção. |
| `README.md` | Este arquivo de ajuda. |

## Funcionalidades das páginas

- **Cabeçalho (header):** presente em todas as páginas, contém o nome do petshop, informações de contato/endereço e o menu de navegação (Início, Produtos, Serviços).
- **Corpo (body):**
  - Na página inicial: texto de apresentação do petshop e resumo do que é oferecido.
  - Na página de produtos: listagem de 2 produtos por categoria (3 categorias), cada um com imagem, descrição e valor.
  - Na página de serviços: listagem dos serviços de banho e tosa, com e sem tele-busca, cada um com descrição e valor.
- **Rodapé (footer):** presente em todas as páginas, contém informações legais (CNPJ fictício), contato, links de navegação, autoria do site e direitos autorais.

## Como navegar

Basta abrir o arquivo `index.html` em um navegador (ou acessar o link do GitHub Pages) e utilizar o menu no cabeçalho ou rodapé para transitar entre as páginas Início, Produtos e Serviços.

## Tecnologias utilizadas

- HTML5 (sem customizações de CSS/Bootstrap e sem JavaScript, conforme escopo da Fase 1).
